# Nút bấm — chạy không cần gõ Terminal

> Cho người **không rành dòng lệnh**. Nhấp đúp file hợp máy bạn: **`.command`** (macOS) hoặc **`.bat`** (Windows). Cửa sổ đen hiện ra chạy xong rồi chờ bạn bấm Enter.

| Nút | Làm gì |
|---|---|
| **1-Kham-tu** | Khám + tự dọn tủ bộ nhớ (chạy bác sĩ) + in lại bảng tiến độ & sổ năng lực |
| **2-Nang-cap** | Nâng cấp một tủ đã cài (cũ) lên bản kit này — hỏi đường dẫn, tự sao lưu, giữ dữ liệu |
| **3-Dong-gop** | Gói cải tiến phần KHUNG gửi maintainer — hỏi mô tả, tự quét rò chặn dữ liệu riêng |

## Lưu ý
- **Cần cài Node.js** trước (nodejs.org) — nút chỉ gọi các công cụ trong `tools/`.
- **macOS lần đầu** có thể báo *"unidentified developer"* → **chuột phải vào file > Open** (chỉ cần 1 lần), hoặc System Settings > Privacy & Security > Open Anyway.
- Nếu nhấp đúp `.command` mà mở bằng trình soạn thảo thay vì chạy: chuột phải > Open With > Terminal.
- **Cài MỚI từ đầu** (điền sổ tay + nối hook) thì làm theo `../HUONG-DAN.html` hoặc **nhờ trợ lý AI làm hộ** (cách nhẹ nhất) — nút bấm lo phần vận hành lặp lại.
